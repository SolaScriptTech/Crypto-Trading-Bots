# Risk Disclosure

Some scripts in this repository can place live financial orders.

Automated trading can lose some or all allocated capital. Risks include software defects, incorrect configuration, stale data, exchange outages, API changes, rate limits, latency, slippage, partial fills, fees, inadequate liquidity, corrupted state, strategy overfitting, and differences between backtests and live execution.

No code, comment, signal, backtest, or historical result in this repository is financial advice or a guarantee of future performance.

Use dedicated credentials with the minimum required permissions. Keep withdrawal permissions disabled. Validate strategies in paper trading and monitor any live experiment continuously.
